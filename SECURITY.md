# Security policy

## Reporting a vulnerability

Please do not open a public issue or pull request for a security problem.

Report it privately through [GitHub security advisories](https://github.com/o1exchange/o1-launch-contracts/security/advisories/new). Include:

- the affected contract and function;
- a description of the impact;
- a proof of concept, if you have one.

We will acknowledge your report and keep you updated while we investigate.

## Scope

All contracts in `src/` and their deployments listed in the [README](README.md#deployments).
